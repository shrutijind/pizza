izza – Frontend Developer Test Project

About the project

izza is a responsive pizza restaurant website built for a frontend developer assessment. The aim is to recreate the supplied design using HTML, CSS and Bootstrap.

The website has a hero image, navigation, menu cards, an Our Story section, a newsletter promotion, location information and a footer.
Technologies used
- HTML5 for the page structure
- CSS3 for styling and responsive layouts
- Bootstrap for layout and utility classes
- Google Maps iframe to display the restaurant location

Features
- Full-width hero background image with navigation over it
- Menu cards for restaurant items
- Our Story and newsletter sections
- Location section with a View Map link
- Separate map.html page displaying the supplied Google Map centred over the hero image
- Responsive layouts using CSS media queries

Responsive design
The layout is designed to adapt to desktop, tablet and mobile screens. The menu grid changes from three columns on desktop to fewer columns on smaller screens. Content sections stack vertically on mobile, and the map scales to the available screen width.


SEO and accessibility
The project uses semantic HTML elements, descriptive headings and image alternative text. The map iframe should have a descriptive title. The site can be improved further by checking that each page has a unique title and meta description, all navigation links work, and images are optimised.
